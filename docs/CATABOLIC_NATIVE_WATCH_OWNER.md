# Native watch owner candidate (Motion 93)

This is an internal, unlaunched owner, not completed public watch parity.
The existing native source-event snapshot, sequence acknowledgement, dirty
 generation and observation claim owners remain authoritative. Motion stores
only authorized immutable watch configuration revisions and immutable links
from an exact native generation to an accepted scan request.

Each new invalidation or missing-link repair obtains the actual current saved
requester credential/ingress, complete current library selection, exact source
mapping and active lifecycle under the same Motion writer. That writer moves
into the retained-host closure. Native dirty generation is descriptive and
cannot authorize a request on its own. If native commit precedes Motion commit,
repair repeats these checks without inventing a new dirty counter.

Filesystem collection is permitted while a native observer is detached. Native
invalidation and demand admission are not. A batch is acknowledged only after
its request and immutable generation link commit; exact sequence ACK cannot
consume a later collected event. A later generation gets a distinct request
even while an earlier generation remains queued or running. Linked failure or
cancellation remains the original request outcome, never implied coverage.

Accepted requests retain the established bounded service-owned work policy.
Configuration edits do not retroactively change their source set. Effect checks
still require the exact immutable occurrence/request/source proof and current
active source lifecycle; explicit scan cancellation continues to revoke work.

## Required before launch

- Qualify the genuine cutover/actor revocation/detached helper/ACK/restart/source
  withdrawal tests. Source-ready tests are not claimed passing.
- Implement a truthful administrative inventory/adoption contract for existing
  implicit legacy watches. An internal complete physical/historical inventory
  candidate now exists, with retained-host activation verification; it is not
  yet qualified or a public contract. Legacy watching retained no requester credential;
  absence of a native configuration must be exposed as requiring authorization,
  not silently interpreted as an empty watch set or converted to operator power.
- Add production timer/event-loop ownership, bounded fairness and terminal
  shutdown custody, then qualify actual main-process behavior before gates.
- Root relocation remains a separate receipt-backed binding succession owner.
  This owner rejects changed mapping/lifecycle/snapshot, never rebinds a source.
